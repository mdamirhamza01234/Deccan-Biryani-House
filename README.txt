DECCAN BIRYANI HOUSE WEBSITE

HOW TO PUBLISH ON GITHUB PAGES
1. Extract this ZIP.
2. Upload the contents of the deccan_biryani_website folder into the root of your GitHub repository (index.html must be at repository root).
3. Open repository Settings > Pages.
4. Select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to publish the site.

FEATURES
- Responsive restaurant homepage and food cards
- Category filtering and food search
- Portion selection for half/full items where known
- Cart, quantity controls, item removal and subtotal
- WhatsApp order request
- Table reservation with guest count, date and 15-minute time choices
- Google Maps embed/directions, direct call and WhatsApp links
- Demo menu admin (see below)

IMPORTANT LIMITATIONS
- Food photos are loaded from Unsplash URLs, so an internet connection is required and image URLs may change. They are illustrative food photos, not verified photos of the restaurant's actual dishes.
- The provided menu prices were transcribed from the supplied menu image. Biryani prices were not legible/provided, so they are marked as price on request. Confirm all current prices with the restaurant before publishing.
- WhatsApp ordering and reservation submit requests to the restaurant; they do not confirm orders, table availability, delivery, or payment automatically.
- This is a static frontend. It has no real payment gateway, inventory, secure login, order database, or multi-device backend.
- Demo admin password: deccan123. Admin changes are stored only in the current browser's localStorage and are not secure. Change/remove this demo before public use. For a production admin dashboard, connect a backend/database and secure authentication.
- The time-slot list is a requested-time picker, not live availability. Restaurant must confirm reservation.
